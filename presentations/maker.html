    Helpful snippets

    Content fields accept Markdown. You can also paste HTML for custom components.

    • **Bold text** → bold emphasis.
    • - Bullet item → checklist styled list.
    • Use <div class="chip">Chip label</div> to render chips.
    • Add <div class="grid cols-3">...</div> in single layout for nested grids.
